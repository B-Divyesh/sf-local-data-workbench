How it works

Turn a source file into a repeatable result.

Open a file, name each change, and save the recipe beside your output.

  1. 01

    Open a local file

    Read CSV, JSON/JSONL, and Parquet directly from disk.

  2. 02

    Inspect the facts

    See inferred types, missing values, distinct counts, ranges, total rows, and a source fingerprint.

  3. 03

    Name each change

    Filter, clean, rename, and select through explicit recipe steps.

  4. 04

    Save a recipe

    Save a readable .ldw.json recipe and reopen it for the same source.

Saved recipe

Keep each transformation in a JSON recipe.

Every step has a name, inputs, and a fixed position. The JSON recipe carries a source fingerprint and schema version for review and replay.

  • Readable, diffable JSON
  • Source identity and format
  • Ordered transformation docket
  • Portable recipe file

Privacy and releases

What does the local-workbench test prove?

It opens, filters, and exports a selected fixture while recording no request to another origin.

What does an unsigned package mean?

Its SHA-256 checksum is published, but no macOS or Windows signature is claimed. The release card states the current signing status.

Where are the application and native notices?

Every desktop installer includes the MIT application license, third-party notices, and the Apache 2.0 notice for the Arrow Parquet dependency.
